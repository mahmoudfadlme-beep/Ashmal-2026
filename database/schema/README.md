# JSON Schema Files

ملفات تعاريف البيانات باستخدام JSON Schema Draft 7

## الملفات المتاحة:

1. **tasks.schema.json** - تعريف هيكل المهام
2. **employees.schema.json** - تعريف هيكل الموظفين
3. **categories.schema.json** - تعريف هيكل الفئات

## التحقق من الصحة:

استخدم أي من هذه الأدوات للتحقق من البيانات:
- [JSON Schema Validator](https://www.jsonschemavalidator.net/)
- `ajv` (npm package)
- `json-schema-validator` (java)
