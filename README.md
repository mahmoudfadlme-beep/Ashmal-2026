# Ashmal-2026 📋

**نظام إدارة المهام المتقدم - Task Management System**

تطبيق متكامل لإدارة المهام والمشاريع بكفاءة عالية مع دعم المزامنة الفورية والتعاون الفريقي.

## 🎯 المميزات الرئيسية

- ✅ **إدارة مهام متقدمة** - تنظيم وتتبع المهام
- ✅ **مزامنة فورية** - Real-time Updates
- ✅ **تعاون فريقي** - Multi-user Collaboration
- ✅ **لوحة تحكم تفاعلية** - Interactive Dashboard
- ✅ **API متقدمة** - RESTful API
- ✅ **نظام إخطارات** - Notifications System
- ✅ **تقارير شاملة** - Advanced Reports
- ✅ **دعم اللغة العربية** - Arabic Support

## 🚀 البدء السريع

### Backend Setup
```bash
cd backend
npm install
npm start
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
